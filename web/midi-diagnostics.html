MIDI connection check

This check only asks for the device identity. It does not enter update mode, upload a loader, or write firmware.

Close Studio, the installer, and other MIDI apps before checking. Disconnect unrelated MIDI devices. If checking a failed loader handoff, leave the SMK in its current state and run this check before power-cycling it.

Use Chrome or Edge. Allow MIDI/SysEx access when prompted.

The log stays in this page until you save or share it. It records device names and identity replies, not your playing.
