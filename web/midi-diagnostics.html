MIDI connection check

Close Studio, the installer, and other MIDI apps. Disconnect unrelated MIDI devices. Use Chrome or Edge and allow MIDI/SysEx access when prompted.

1. Check identity

This check only asks for the device identity. It does not enter update mode, upload a loader, or write firmware.

If an installation has already stopped at the loader handoff, leave the SMK in that state and run this check before power-cycling it.

2. Test stock loader handoff

For stock SMK-37 Pro 016 or Elite 016 only. Start with the normal factory screen and select its -Private MIDI output above. This test loads the verified official RAM updater and records its MIDI ports and identity for 30 seconds.

This changes the device into loader mode; its screen may go black. The diagnostic does not send the application firmware or start the flash-writing stage. Keep USB and power connected until the test ends. Then save the log and power-cycle the SMK to return to stock firmware.

Use an official firmware file from your computer (optional)

The test normally downloads the official 016 file from a pinned mirror and verifies its SHA-256. If that download fails, select your original, unmodified .fwsc file here.

The existing installer’s model checks remain unchanged. An unexpected loader identity is recorded for investigation, not accepted for flashing.

Enable MIDI access to begin. Nothing starts automatically.

The log stays on this page until you save or share it. It includes browser information, port names and IDs, identity replies, and loader request addresses—not your playing. “Closed” means this page released a MIDI port; it does not mean USB disconnected.
